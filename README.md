# lexy-site

Public website for the Lexy voice notes app, served with GitHub Pages at <https://lexy.casim.net>.

- `index.html` – home page
- `privacy-policy.html` – privacy policy (Play Console privacy policy URL)
- `terms.html` – terms of use
- `delete-account.html` – account deletion steps (Play Console data deletion URL)
- `app-ads.txt` – AdMob seller verification
